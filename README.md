# Calorie Calculator

A small, in-progress web app for calculating nutritional values

**Status:** In progress :]

## Quick start
- Open `index.html` in your browser to run the app locally.
- Use `register.html` to create a new account if the page is present.

## Current features
- Calculation of nutritional values based on: weight, gender, height, sports activities and age
